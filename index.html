🔗 Relier à votre tableau Google Sheets

Collez l'URL de votre script Google Apps Script ci-dessous pour synchroniser vos onglets (Interventions, Contact, Plan, Historique) directement avec votre Google Sheets :

Voir comment activer le lien dans Google Sheets (4 étapes simples)
  1. Ouvrez votre fichier Google Sheets et vérifiez que vous avez les onglets ou colonnes Interventions, Contact, Plan, Historique.
  2. Dans le menu en haut, cliquez sur Extensions > Apps Script.
  3. Effacez tout le texte, collez le code copié avec le bouton ci-dessus, puis cliquez sur Déployer > Nouveau déploiement.
  4. Choisissez le type Application Web, accès : Tout le monde, cliquez sur Déployer et copiez l'URL fournie dans le champ ci-dessus.
